## Context

用户要求：投资周期可选，作者自动订阅为主流程，三市场架构可选；监控默认关闭，只有用户主动开启才持续采集。现有代码只有 US/HK 硬规则，新闻摘要和股票评分分离，已安装新闻源全关闭。现有 `run_news_scan` 在通知去重之前截断为五条，provider 错误返回空列表，均应修复。

## Goals / Non-Goals

**Goals**：实现可用的本地研究工作区、可操作控制、自动更新发现、可引用的完整材料分析、多周期条件化建议以及可靠的失败/等待状态；全部实现和实际验收进度以 tasks.md 为准。

**Non-Goals**：自动交易、收益承诺、绕过平台登录/付费/访问控制、伪造全平台订阅能力、用模型自报分数充当获利概率、在未获授权时购买服务或开通收费账号。

## Decisions

### 1. 监控生命周期

研究监控状态属于 Guardian 当前会话：`STOPPED → RUNNING → STOPPING → STOPPED`。设置和订阅可保存，运行意图不持久化为自动启动。初始化、UI读取、刷新回执和应用打开均不得启动新闻研究。用户启动时选择 1–1440 分钟间隔；单次扫描不创建周期任务。只有显式开始后才注册研究周期任务，停止移除调度并撤销本轮后续分析/提醒许可。正在进行的有界 HTTP 请求允许收尾，但返回结果不能启动新的后续请求。后台进程重启后恢复 STOPPED；仅关闭桌面窗口会明确提示仍在后台运行，并提供停止入口。

旧新闻四小时任务不再自动注册。旧 `news` CLI 保留显式单次扫描兼容性；研究 CLI 提供受控的一次扫描/前台跟踪。股票规则巡检原行为不扩大为新闻授权。

### 2. 数据与责任

新增 `research` 包，Guardian 独占后台执行；UI只走鉴权IPC。SQLite `research_*` 表保存订阅、证据、报告和扫描结果，与既有规则状态隔离。新表迁移前备份已有数据库；内容与报告持久化后才展示完成。存储成功资料不会因界面刷新而重新采集。

证据身份使用平台内容ID或规范URL；正文/字幕/时间片段SHA256用于内容去重，证据版本另包含标题、作者和原发布时间。每个来源保存最后一次实际观察到的版本：较新的标题或不完整材料会阻止旧全文复用，分析历史记录不会回退这个版本。旧库迁移前自动备份，相同旧记录保持原ID和取得时间。记录原始发布时间、发现/获取/分析时间，缺失时间明确为空；旧内容重新发布不能自动冒充新事件。记录材料完整度 `metadata/summary/article/transcript`、质量问题及来源簇；跨平台转述不得增加独立佐证数。报告缓存绑定证据版本、分析器版本、市场和周期。

### 3. 采集与平台能力

每个来源独立返回 `success/partial/failed/disabled/needs_configuration/permission_required/unsupported`，空结果只有真实成功调用才代表暂无新内容。使用有界分页/数量、超时、退避、并发和批次预算；通知先去重再限额。

RSS/Atom 和 YouTube 公开频道 feed 用于自动发现更新；作者 handle 需解析为稳定频道ID。B站公开稿件、文章/字幕在真实可访问时接入，接口失败按来源独立报告。抖音/小红书通过经过验证且已授权的来源渠道接入；没有所需授权时保留订阅并显示待配置，不把平台主页HTML或简介当成视频转写。用户可补充正文、带时间戳的字幕或授权feed。音视频转写必须有可用的获取路径和转写提供者，处理状态和成本单列。

外部URL仅允许HTTP(S)公网，校验每次跳转、DNS及响应大小，禁止本地/私网/凭据URL，防止研究入口访问本机服务。外部文本均为不可信数据，不能成为指令；错误只输出低基数原因，密钥不进入数据库或UI。

### 4. 分析与建议

结构化分析提取 claims（fact/opinion/inference）、逐条引用、公司/产业关系、支持/反对证据、催化事件和可验证假设。每条引用须属于已保存证据并匹配原文，视频引用包含开始/结束秒及说话人；未核实观点保持观点。标题或简介不足以产生方向性建议。

短线关注新信息、即时价格/成交/流动性和有效期；波段关注事件兑现窗口及验证节点；长期关注业务/现金流/竞争与估值。相同证据可产生不同周期报告。建议状态为研究候选、观察、持有复核、减仓复核或证据不足；具体数值条件仅取自可核实数据，缺失时留空，不虚构股价/目标价/胜率。买入候选至少需要可引用完整证据、已识别的证券、可用行情和与周期匹配的数据质量；矛盾或过期时撤销/降级建议。仓位建议留待用户提供风险与持仓后开展。

### 5. 市场独立验收

研究市场使用 `US/HK/CN`，币种 `USD/HKD/CNY`，证券身份包含交易所；同家公司多地上市不能合并为同一证券。US/HK复用现有fetcher但不把observed_at视为交易时间。CN优先接入明确标注交易日的日线数据；缺少可信盘中时间/成交信息时不启用短线建议。普通A股T+1、板块涨跌幅和证券状态作为规则档案，版本化记录生效时间，不写死所有A股同一比例。仅扩展研究域不会将A股伪装成旧硬规则引擎已支持。

### 6. UI 与验收

桌面提供“研究”页：监控状态、立即扫描、开始/停止、间隔、市场/周期多选、作者订阅列表及新增/暂停/删除、来源健康、证据列表、报告详情、原文/时间戳。等待内容/未配置模型/数据过期可直接辨识；刷新只读取已保存结果。耗时任务异步运行，重复点击不重复执行；停止后不得有新网络调用链。

先通过离线契约和UI测试，再用真实公开来源做读取验证。完整的外部平台声明需指定实际作者、内容获取、持续更新、失败恢复的证据；只有fixture通过不能标记生产可用。研究质量按市场×周期回放，使用当时可见信息、来源延迟、成本及不可成交条件，不能用后验信息修饰历史建议。

## Risks / Trade-offs

- 官方字幕接口与博主订阅不是同一种授权。能力不足必须可见，不能以非官方接口偶尔成功推断稳定可用。
- 当前为本地程序；睡眠/断网时无法保证连续运行，恢复后有界补采并显示覆盖缺口。分钟频率是本地检查间隔，非上游实时保证。
- 来源、模型及转写成本按批次限制；高频采集不重复分析内容未变化的证据。
- 用户希望全部落地后汇报；实现不能把需要外部授权的真实验收标成完成。全部可独立推进的工作先完成，再明确剩余输入。

## Migration Plan

1. 备份既有状态库并增量创建研究表，保留旧数据。
2. 默认关闭旧隐式新闻任务；已有来源启用不等于监控启动。
3. 交付桌面与CLI能力、运行离线回归及构建检查。
4. 实测公开来源；有授权依赖的平台记录未完成验收和恢复步骤。
5. 同步README/产品文档，分别说明研究建议与旧规则提醒的语义。

## Open Questions

用户于 2026-10-02 完成 B站、抖音、小红书专用浏览器登录，真实关注的博主清单及付费数据额度尚未指定；验收使用公共财经作者样本，不自动加入用户订阅。本机 Whisper 已安装，真实材料的识别质量和各平台完整正文验收分别记录，不能用合成语音或标题更新替代。
## 本机模型与浏览器接入补充

模型除了现有 Anthropic API 外，支持显式配置 `claude_cli` / `codex_cli` 提供者，使用本机客户端自己的登录；不导出或转存 OAuth 凭据。分析子进程禁用命令执行、外部应用、技能和 hooks，不保留会话，限制输出大小和执行时间，支持停止进程树；Claude 限制单轮，Codex 使用只读沙箱并检查单轮完成及无工具调用结果。不同提供者和模型的提取缓存隔离。AI 开关和监控仍默认关闭；客户端额度和登录可用性以实际调用结果为准。

视频和社交平台可启用正常 Chrome 页面读取。默认使用 Alpha Guard 专用持久 profile，登录由用户在可见窗口完成，不迁移日常浏览器 cookies。备用 existing 模式需 Chrome 允许调试连接。应用只管理自己创建的页面，固定代码提取当前作者作品和正文/字幕；平台登录、验证码、访问拒绝或内容不全保留明确状态，不绕过限制。浏览器读取只发生在手动扫描或用户开启的跟踪中。

## 无字幕视频的有界本地转写

`VideoResearch` 在每轮扫描内共享播放次数与转写额度，默认关闭；启用后每轮 1～5 条、每条最长 60～600 秒，先读取原生字幕。无可用字幕时，正常页面校验视频和作者身份、排除广告后，从原播放器的音轨捕获完整原速播放。禁用麦克风/屏幕录制路径，不复制或重放媒体 URL、签名及 Cookie。专用自有页面在导航前静音。

完整性同时要求原生 ended、从起点连续播放、媒体身份和速度未变化、实际解码音频时长与视频匹配、转写片段不越界。等待广告不消费唯一的录制时长扩展。页面音轨有固定字节和分块上限，临时文件在结束或取消后删除。停止结束自有页面及转写进程树；超限或不完整内容保持可见失败状态。长访谈通过原生全文字幕或用户的完整本地文件导入。

完整机器转写立即存为原来源证据，后续来源失败不丢弃它。同一稳定来源最新版本的标题和发布时间未变时复用原转写，原始获取时间不刷新；较新的元数据/部分版本构成屏障，不能回退旧全文。该复用不等于确认原视频从未编辑。小红书正文与图片区分：正文可完整保存，但未读取图片会进入强制观察门禁。分析器版本更新为 `evidence-research-v4`，避免沿用旧质量规则的报告身份。
