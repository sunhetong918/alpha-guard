## 转写与取消边界

- SRT/VTT 的真实解析、说话人、时间戳及入库模型已有离线测试；缺失时间不会被补成 0 秒。
- 本地已安装独立 Python 环境、官方 Whisper `20250625` 及经过官方 SHA-256 校验的 tiny / base 模型。使用本机合成的相同中英文录音，实际通过 `ResearchService` 调用模型并把识别原文及时间片段写入独立 SQLite；默认选择 base。英文 17.191 秒录音、中文 15.777 秒录音的 base 全链路耗时分别为 3.686 秒、3.233 秒。完整命令、原始质量问题和可重复验收见[本机转写验收](research-transcription-validation.md)。
- 两个模型都出现了中文同音字错误，base 仍把“不包含”识别为“部包含”。这次验证的是**真实语音识别技术链路，材料为合成语音，不是实际投资访谈质量验收**。机器转写保留未经核验标记，不能直接成为方向性投资候选；人工核对后可导入修正字幕。
- POSIX 取消终止本次进程组；实际 tiny / base 子进程在停止后分别于 0.071 / 0.100 秒退出，没有新增证据，服务及重新构造后的状态均为 STOPPED。Windows 使用固定系统 `taskkill` 指定本次 PID 和其子进程树，不使用 shell；该分支有模拟测试，本机未执行 Windows 真机转写。
- 停止后不再开始新的来源请求或行情 provider 操作；已经开始的有界操作允许收尾。应用读取和刷新不触发这些烟测。
