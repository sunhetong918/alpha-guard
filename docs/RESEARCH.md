# 按需投资研究

研究工作台把新闻、指定博主和访谈材料存为有来源的证据，再按短线、几天至几周、中长期分别生成研究判断。每条报告保留引用、当时行情、成立条件、反证、待核实事项和有效期。研究结果不会修改已配置的规则或提交订单。

未完成工作、竞品源码借鉴及具体验收条件统一维护在 [OpenSpec](../openspec/specs/alpha-guard/spec.md)。真实第三方模型、通知接收和持续运行分别验收；本页说明当前功能的使用方法。

## 自选、核验与事件

1. 侧栏 **自选股票 → 自选与规则**，填写市场、代码和名称。搜索只查本地自选，保存不会开始采集。研究关注与规则监控分别设置；原有监控状态在“监控证据”标签。
2. 选择证券后 **编辑监控规则**，设置价格、估值或 ROE 条件、成本、冷却与启用状态。预览确认后保存；下次扫描重读规则，不需要重启。A 股目前只提供研究。其他窗口改过配置时必须重读再确认。研究关注最多 100 只；向导每侧最多编辑 100 条规则，超限旧配置会明确提示并保留，不能被不完整覆盖。
3. 从证券进入 **核验与复盘**，或在报告详情点击“核验与复盘”。按证券、日期、核验状态找报告，保存待核验/已核验/暂不采纳、备注和下次核验时间。它们是你的处理记录，不改原报告，也不会提升系统的证据质量。
4. 复盘先显式导入价格样本 JSON，界面可复制格式示例；再选择报告和截止时间执行。样本来源、来源时间和取得时间必填。结果区分等待、已观测、无法评价，保留原因。未复权价格变化不是投资收益，导入值没有经过独立查证。
5. 从证券进入 **事件日历**，按证券、类型和日期查看财报、公告、分红、拆股。可以录入或导入有来源链接、稳定来源事件 ID 的记录；改期保留历史。分红分别记录公告、除息、登记和派息日，未知时刻只显示日期。

在自选行双击或点击 **证券研究概览**，可以一起看关注与规则状态、该证券最近扫描、最近五份报告、待核验数量和未来事件。报告、核验和日历可直接进入；返回保留列表位置和未保存内容。尚未采集、空结果、失败和过期分别显示；旧历史没有逐证券扫描时间时不会借用其他证券的扫描时间。

**自动事件覆盖**：只有点击公开来源刷新才联网；首版读取 Yahoo chart 近一年的历史分红/拆股，支持来源可提供的美股/港股。2026-10-16 产品路径实测返回 `permission_required`（HTTP 401/403），当前自动来源不可确认可用；请先录入或导入。未来财报、公告、未来分红和 A 股自动事件尚未接入，可先手工录入或 JSON 导入。读取日历、导入记录都不自动发送提醒。来源失败会保留旧记录，并显示失败和最后成功时间。

日历按来源、证券、事件类型和日期范围显示“已查询、已查无记录、未查询、不支持、查询失败、缓存过期”。历史来源仅覆盖近一年；成功获取的覆盖预算为 24 小时，缓存按原始取得时间计算。局部失败保留此前成功时间和记录，查询未返回旧事件不表示撤销。单次查询最多检查最近 200 条范围记录，无法证明的范围显示“无法确认”。

### 本地只读持仓

在“自选股票 → 只读持仓”填写账户本地别名和快照日期，选择 UTF-8 CSV 或手工粘贴。映射市场、证券代码、数量及可选的单位成本、成本币种；文件最多 500 行、256 KB。数量与单位成本支持非负数、最多八位小数；成本和币种必须成对填写，支持 USD/HKD/CNY/EUR/GBP/JPY/CHF/CAD/AUD/SGD。

勾选完整快照后点击“校验并预览变更”；逐行解决错误，核对未识别证券后勾选确认并重新预览。首次出现的证券确认只表示用户核对身份，不代表行情源验证。点击“提交完整快照”才写入；未列出的证券和零数量证券会移除，负持仓不支持。重复导入不累加，发生并发修改时要求重新预览，保存失败整体回滚。可读取同一账户快照或撤回到上一份；撤回首份后为空。只保留安全文件名，不保存原始文件路径。

导入不连接券商、不联网取价、不触发研究或提醒、不修改监控规则。成本是每股单位成本，不是市价。

### 只读集中度

持仓页下半部分在同一快照上计算**单股与币种占比**：设置基准币种（可不统一）、单股/币种提醒阈值（仅展示，不发通知）与前 N 大数量后保存。点击“联网取价（显式）”才会取价与取汇率：每次最多 60 项报价、9 项汇率，总时长 90 秒、单项 10 秒，超预算的项保持不可估；报价与汇率连同来源、时间、换算方向一起保存，读取与计算不联网。报价/汇率超过 7 天视为过期。

市值 = 数量 × 同币种有效报价；统一基准时按记录了方向与时间的汇率换算（如 `1 HKD = <rate> USD`）。缺价、缺汇率、过期或时间未知的持仓列为**不可估**并给出原因，绝不用 0 填充；分母只含已估值部分并明确标注“已估值部分”，不冒充完整组合占比。币种构成按报价币种统计并标注“不代表完整经济风险敞口”。单位成本只用于成本口径，不参与市值。首版不含行业分类、投资收益、胜率、税费与自动调仓，也不发送集中度提醒。


## 开始与停止

桌面侧栏进入“投资研究”，选择市场、周期、证券、新闻源和扫描频率后保存。证券格式为 `US:AAPL, HK:00700, CN:600519`；研究证券单独配置，不会自动启用规则监控。

- **扫描一次**：完成一轮后停止，不留下定时任务。
- **开始跟踪**：立即扫描，完成后按选定间隔继续。频率为 1～1440 分钟，初始值 15 分钟。
- **停止跟踪**：清除后续执行，在当前有界请求返回后停止，不继续采集下一来源或分析下一材料。

安装、打开页面、添加订阅、保存设置及 Guardian 重启都不会开始采集。研究进行中关闭窗口会提供继续后台、停止研究后关闭或取消的选择；选择停止须等实际停止回执，失败会保留窗口。退出 Guardian 后停止；重启必须再次手动开启。原来每四小时执行的新闻任务已取消。原有股票规则的交易日调度仍独立运行。

这属于主动开启的定时采集。新鲜度取决于上游发布时间、访问能力和所选间隔，界面不会将延迟新闻或日线行情标成交易所实时数据。

## 任务进度与续跑

在 **投资研究 → 任务与续跑** 查看批次和每条材料的进度、失败原因、原报告、累计模型调用及预算。只读分页和刷新不会调用模型。单次扫描在分析阶段取消或中断后，可选择原批次并点击 **继续所选批次**；已经完成的条目不会重复分析，成功报告和完成状态一起保存。

继续使用原证据与行情快照，不重新采集。证据、配置或分析器变化，跨过原批次 UTC 日期、行情过期或预算耗尽时，会说明原因并要求新扫描；采集阶段中断和连续跟踪不支持续跑。重启只将遗留运行标为中断，不自动开始收费调用。

模型调用发出前已扣减本批次额度。若进程中断导致结果未确认，界面会要求勾选“理解可能增加调用费用”后才允许继续；可能已发生的调用不会从预算中抹去。外部调用无法保证恰好一次，继续仍可用研究页的停止按钮取消。

## 博主订阅

添加平台、作者主页、名称，以及可选的合法 RSS/Atom 来源地址。添加只保存配置；开始扫描后才访问来源。

| 平台 | 更新发现 | 正文或字幕 |
|---|---|---|
| RSS / Atom | 读取公开 feed | 保存 feed 完整正文；摘要会尝试读取公开原文 |
| YouTube | 频道 feed；失败时可读取作者 Videos 页最新作品 | 公开或正常页面加载的字幕；可选完整音轨本地转写；不可访问时保存元信息并标记等待内容 |
| 哔哩哔哩 | 公开更新接口，或启用浏览器后读取作者最新投稿 | 公开字幕或正常登录页面的字幕；多 P 只获得首段时明确标成部分内容 |
| 抖音 | 合法作者 feed，或启用浏览器后读取已登录作者页面 | 可选完整播放器音轨的本地转写，受数量和时长额度限制 |
| 小红书 | 合法作者 feed，或启用浏览器后读取已登录作者页面 | 读取图文正文；图片未读取时标记并降为观察；视频支持可选本地转写 |

接口风控、登录要求、无字幕和仅有标题都不会被当成完整材料。当前没有内置抖音/小红书 OAuth 授权服务，也不会绕过登录、验证码、付费墙。详情区区分更新发现与内容完整度，采集失败保留此前证据。支持暂停或删除订阅；删除订阅不删除历史引用。

浏览器接入默认关闭。设置 `ALPHA_GUARD_BROWSER_ENABLED=true` 后，主动扫描可以启动本机 Chrome 的 Alpha Guard 专用资料目录，在正常窗口完成平台登录。默认 `ALPHA_GUARD_BROWSER_MODE=dedicated`；读取时会把本次创建的内容标签置前，以便页面加载。它不复制日常浏览器 Cookie，不代填密码，不绕过验证码；仅关闭本次内容标签，保留专用窗口与平台登录。缺少登录、平台服务异常与字幕不可用会分别显示。实际平台验收状态见[平台访问记录](research-social-platform-validation.md)。

在“博主订阅”页选择平台并点击“打开平台登录”，可先在专用 Chrome 中自行登录；此动作保留登录页，不启动扫描，也不代表登录已经验证成功，现有浏览器模式请直接在已连接的 Chrome 中登录。

授权 feed 地址不得夹带 token/API key。只接受公开 HTTP(S) 地址，检查 DNS 和每次跳转，拒绝本机/内网和自定义端口；读取有超时、大小、条数上限。也可以由拥有授权的来源服务提供可读取内容，或明确导入已取得的材料。

## 访谈和转写

研究设置中的“无字幕时本地转写视频”默认关闭。开启后，在主动扫描中先尝试原生字幕，无字幕时从正常播放器完整提取音轨，再在本机转写。默认每轮最多 2 条、每条最多 10 分钟；可设置 1～5 条及 1～10 分钟。播放静音且按原速进行，因此扫描会花费视频的实际长度和转写时间，不访问麦克风或录制屏幕。可随时停止。长访谈使用完整原生字幕，或走下述完整文件导入；超限时不会把前几分钟标为全文。

平台页面必须与指定视频及作者匹配。源切换、登录失效、播放中断、时长不符或转写片段超出音频会保留等待状态；临时音轨处理后删除。完整转写按稳定来源保存，标题和发布时间未变时复用原证据，避免重复播放和转写；复用不是重新核对原视频是否修订，也不会刷新原证据的取得时间。

可导入正文、SRT、VTT 字幕，并填写原文链接、作者和真实发布时间。字幕保留时间片段；普通文字没有时间戳时不会伪造视频定位。只有摘要的材料不会产生方向性候选。

本地音视频可通过已安装的 Whisper 兼容命令转写。此命令由运行环境配置，界面与外部材料不能注入可执行命令。示例：

```bash
export ALPHA_GUARD_TRANSCRIPTION_COMMAND='["whisper","{input}","--output_format","json","--output_dir","{output_dir}"]'
uv run alpha-guard research transcribe interview.mp4 --source-url https://example.org/interview
```

这要求用户已安装对应转写器及模型，环境变量或 `.env` 配置对 Guardian 进程可见。没有配置时会显示需要配置。当前任务默认最多 15 分钟、媒体最多 2 GB，停止操作会结束转写子进程。机器转写保留“未经核验”标记，录制时间未知也会保留。未经核对的机器转写只能产生观察报告，不能成为方向性候选；核对后可重新导入修正的字幕并保留原始材料。转写完成先进入证据库，下一次显式扫描才分析。本机独立运行环境及中英文实测记录见[转写验收](research-transcription-validation.md)。

## AI、成本与研究判断

模型可以选 Anthropic API，或本机已登录的 Codex / Claude 客户端。桌面勾选 AI 后，只有主动扫描或开启跟踪才发送材料给所选模型，并消耗该账号的调用额度。订阅凭据与 API key 不写入研究证据、报告或错误消息。

使用 API 时安装 `ai` extra，并在运行环境或 `.env` 配置 `ANTHROPIC_API_KEY`。使用本机 Codex 时配置 `RESEARCH_MODEL_PROVIDER=codex_cli`，模型由 `RESEARCH_CODEX_MODEL` 指定（初始为 `gpt-5.5`）；客户端使用自己的现有登录，应用不提取登录令牌。可通过 `RESEARCH_CODEX_EXECUTABLE` 指定已安装客户端的绝对路径。Claude 对应 `claude_cli` 和 `RESEARCH_CLAUDE_EXECUTABLE`；本机本次 Claude 请求超时，真实分析验收使用 Codex 完成。

客户端在临时工作目录运行，禁用命令工具、外部应用、技能和 hooks，不持久化会话；Codex 使用只读沙箱并检查完成事件，结果仍须通过同样的逐字引用和数字来源校验。每次调用受 `RESEARCH_MODEL_TIMEOUT_SECONDS`（初始 180 秒）限制，可随研究任务停止。调用预算按应用发起的分析请求计数，客户端内部网络重试也受总执行超时约束。

```bash
uv sync --frozen --extra desktop --extra ai --extra cn-data
```

默认模型为 `claude-sonnet-4-6`，可通过 `ANTHROPIC_MODEL` 修改。旧默认 Sonnet 4 已停用，替换依据为 [Anthropic 模型生命周期](https://platform.claude.com/docs/en/about-claude/model-deprecations)。

AI 只提取原文事实陈述、作者观点、推断以及证券关系。引用必须逐字匹配持久化原文，访谈引用必须指向有效时间片段。所谓“事实”表示来源中的事实陈述，不表示已经得到独立证实。公司名和证券关系仍须人工复核。

确定性检查随后判断材料完整度、发布时间、行情时效、财务字段和市场能力是否满足对应周期。只获得标题/摘要、时间缺失、行情过期、引用不符、观点冲突时会降级为证据不足或待补充。模型不可输出保证收益、仓位、目标价或假造胜率。

研究设置限制每轮材料数（初始 20）和模型请求预算（初始 10）。相同内容版本和分析配置复用提取缓存；新价格和新内容仍须重新核验。来源出现修订时，旧版报告会标明来源已更新并降为观察，后续扫描只分析当前材料，保留历史原报告供事后核对。无模型配置或模型失败与“分析完成”分别显示。报告有效期与证据、行情的实际时效共同约束，过期不会因为再次展示而恢复有效。

报告详情末尾及核验页的 **查看原报告生成配置** 展示当时保存的模型、配置档案版本、分析器/提示模板、周期及实际生成参数。缓存保留原生成配置；修改或删除模型档案不改历史。旧报告和未执行模型的报告显示“生成配置未记录”，未知参数不填默认猜测；快照不保存密钥、原始端点或本机路径。

## 自定义模型 profile

除内置提供者外，可以在桌面研究页"模型"标签或 CLI 保存自己的模型端点：名称、协议（OpenAI 兼容 `/chat/completions` 或 Anthropic 兼容 `/v1/messages`）、base URL、模型名、超时，可选"允许本机/私网端点"（用于 Ollama、LM Studio 等本机推理）。API key 只存操作系统钥匙串（后备为仅当前用户可读的 0600 本地文件），不进入研究库、日志或错误信息；界面与 CLI 只显示"已配置/未配置"。

同一时刻最多激活一个 profile；不激活时沿用环境变量提供者。激活 profile 的提取缓存按"协议+端点指纹+模型"隔离，不同供应商的同名模型不会互相复用缓存。模型请求走有界客户端：单次 POST、不跟随重定向、响应限量、受超时与研究停止控制；公网端点必须 HTTPS，明文 HTTP 仅限显式允许私网后使用。"测试连接"会发起一次极小的真实请求（可能产生费用），用于确认端点与密钥可用，不产生研究证据。

弱模型的输出仍要过同样的逐字引用与数字来源校验；校验不通过就如实失败，不会因为换了模型而放宽质量门槛。真实第三方供应商的可用性以你自己的 key 实测为准。

## 每日摘要

研究页"每日摘要"标签提供默认关闭的每日计划：显式开启并设定本地时刻后，Guardian 在该时刻聚合一次已配置来源（新闻源与已启用订阅的文本材料；不录音、不转写），按关注清单生成摘要。**这是与连续监控不同的独立授权计划：显式开启后 Guardian 重启会继续执行；关闭即取消；Guardian 离线错过的时刻不追补，缺口在摘要记录中如实标注。**

关注清单 = 研究设置的"关注股票"（代码与名称匹配）+ 摘要设置里的主题关键词。匹配与排序是确定性规则（证券命中、主题命中、24 小时内发布、跨来源佐证），相同输入必然得到相同排序；"热点"仅指已配置来源内的相对排序，不宣称全网热度。无命中的分组保留为空并显示。

可选开启 AI 原文选读：每轮最多一次模型调用，模型选择完整原文标题，服务逐字核对标题与本轮证据 ID。自由改写、删否定词、错配证券或数字会被拒收并回退确定性摘要。这是原文选读，不生成未经核验的综合结论。

投递默认关闭。可勾选 **Telegram**、**WhatsApp** 或两者，保存设置后再生成；开启通知至少选择一项。各通道仍需在 Guardian 配置凭据、接收端及发送开关。Telegram 发送摘要文本，WhatsApp 使用现有静态模板提醒，**不包含摘要正文**。渠道分别显示接受、失败或未配置；“服务已接受”不等于接收端已收到，一个渠道成功不会掩盖另一个失败。CLI 设置字段为 `notify_channels: ["telegram", "whatsapp"]`。

摘要历史保存在本地库，桌面与 CLI（`research digest-*`）可离线分页查看，并从摘要跳转本地证据。一次性 CLI `digest-run` 会等本轮结果保存后退出；请求接受不等于已经完成或送达。

## 市场和周期

- 美股、港股复用现有提供者行情与基本面。免费数据可能延迟；短线需要满足更严格的新鲜度和成交量要求。
- A 股使用带明确交易日期的日线研究，证券身份独立保存。现阶段不输出 A 股日内买卖候选；基本面或交易约束未核验时也会保守降级。
- 同一材料可以分别生成短线、波段和长期报告，观点不必一致。长期候选仍需要财务字段，不能只凭一段博主访谈。

A 股的信息来源并非不公开；政策、行业监管和交易制度需要进入分析条件。美股与港股同样受政策和监管影响，不能据此认为它们可以可靠预测。当前接入差异反映数据和验证能力，不代表市场优劣。


CLI 与桌面读取同一部署实例的 SQLite，跨会话锁防止重复运行。CLI 的运行状态属于当前 CLI 会话；桌面运行状态在研究页查看。读取详情不联网。导入文本只保存材料。

研究表位于现有状态库的 `research_*` 命名空间。首次为已有库建表前使用 SQLite backup API 备份；内容更新保留版本，提取缓存与内容版本关联。桌面快照分批读取最近100条证据和报告、全部订阅；更早记录可通过 `research history` 分页查询。大材料的详情分页传输，完整内容可通过 `research show` 离线读取。

## 历史报告事后跟踪

`research replay` 读取已经保存的原始报告和用户提供的价格样本，按市场与周期汇总。不会重新生成历史判断，不把后来才取得的原文或行情放入报告创建时刻的依据。只有当时实际已取得且时间合格的基准输入才进入统计。

价格文件是 JSON 数组，每项包含 `instrument`（market/ticker）、`price`、`currency`、`source_as_of`、`observed_at`、`provider`、`granularity`（intraday/daily）和可选 `corporate_action`。两个时间都须带时区；尚未获得的价格不参与截止时刻统计。

跟踪终点是报告原定有效期结束后的首个近邻样本：短线容许30分钟，其余周期容许4天；没有相应样本显示等待。结果是未复权价格变化及其与原方向的关系，不是实际投资收益。公司行动标记会排除受影响样本；未知公司行动、成交能力、手续费、滑点和持仓均未建模，不能据此宣称胜率或策略有效。

## 验收边界

离线测试覆盖采集异常、取消、重复开始、默认关闭、IPC、引用校验、多周期降级与桌面交互。真实来源、模型和本地转写器的验收结果应单独记录，不能用测试夹具代替真实可用性。尤其是抖音/小红书完整自动订阅，需要可用的授权来源；仅能保存一个作者地址不算已接通。

开发验收（2026-10-02）：1,255 项全量测试通过，Ruff、81 个源文件 Mypy、OpenSpec strict 与 wheel 安装检查通过。YouTube/B站/抖音/小红书四平台"订阅→自动全文→缓存复用"真实端到端链路已于当日全部通过（见[真实读取验收记录](research-live-validation.md)），历史失败回执仍保留；机器转写质量、跨日持续稳定与更多作者/市场样本仍需持续核对，不能把链路通过等同于内容准确或投资结论有效。当前本机使用无词表 turbo，转写仍需核对，未将模型升级等同于内容准确。

`/Applications/Alpha Guard.app` 本次核查仍为 2026-10-02 产物，尚未包含本轮工作区新增功能；源码验证不代表安装版本已更新。配套 Guardian 的配置文件为 `/Applications/alpha-guard-guardian/.env`，与源码目录的 `.env` 分开。历史安装与配置备份、后台启动检查见上述验收记录；本轮真实第三方模型、通知接收、登录启动和 30 天观察仍单独验收。

## 研究质量核对

材料包位于 `tests/fixtures/research_quality/corpus.json`，共 12 个案例，覆盖多作者、日期、金额、证券实体、引用和字幕术语。Apple/Microsoft 官方摘要与合成样例分别标识；摘录附哈希，修改后须重新核对。合成字幕没有真实音频，不能替代实际转写器验收。

`proposed_label` 是待审校建议，不是人工标准答案。核对人依据原文填写 `human_label`（supported/unsupported/undetermined）、`reviewer` 和带时区的 `reviewed_at`。预测结果文件为 `[{"id": "案例ID", "label": "supported"}]`，不得混入密钥；没有输出的案例保持缺失，无法判定的案例单独保留。

```bash
uv run python -m research.quality_eval tests/fixtures/research_quality/corpus.json
uv run python -m research.quality_eval tests/fixtures/research_quality/corpus.json predictions.json
```

评分工具只读本地文件，不调用模型。未人工审校的案例不进入准确率；结果分别列出误报、漏报、弃答和缺失项。本轮默认 12 项、0 次模型调用、0 美元；真实模型轮次最多 2 次调用、1 美元，执行前必须核实单价及硬 token 上限，无法确认费用上限则不运行付费轮次。真实材料的人工审校与端到端模型分析仍须另行验收。


### SEC 正式披露

事件日历中选择美股（例如 US:SPCX），点击“刷新 SEC 披露（联网）”。阅读、筛选及切换页面不自动联网。当前已验证 SPCX 目录获取，其他美股需要 SEC 官方证券代码表可访问；不保证全市场覆盖。

来源覆盖近一年 10-K、10-Q、8-K、20-F、40-F、6-K 及各自 /A 修订；不包含未来公告计划。披露日、报告期、接收时间原值及精度分别保留，未知时区不生成 UTC 时刻。accession 标识每次提交，同报告期修订稿独立保存。重复刷新不新建修订，失败或停止保留旧记录。

每次最多 20 秒、4 次请求、2 个历史页，每响应最多 3 MB、最多 100 条提交，无自动重试；超限整次失败，不把截断结果标为完整。SEC 覆盖独立于 Yahoo，6 小时后标为过期。正式原文通过详情中的浏览器链接打开；目录成功不代表原文可访问。

SEC Fair Access 要求访问 `www.sec.gov` 原文的 User-Agent 携带可达联系方式（`名字 邮箱`），仅名称、URL 或浏览器 UA 会返回 403；`data.sec.gov` 的目录 JSON 不受此限制。应用内所有 SEC 请求自动使用 `AlphaGuard Research Reader <RESEARCH_SEC_CONTACT>`（默认为仓库所有者公开 GitHub 邮箱，可用环境变量覆盖）。2026-10-21 实测：配置合规 UA 后 SPCX 8-K 原文经应用内抓取返回 200 可读。
