Evidence First

为什么证据优先

大多数工具在数据缺失时选择猜测。Alpha Guard 把「不确定」当作一等公民返回，并让每个结论可追溯、可解释、可复现。

01 缺失即未知UNKNOWN 字段缺失、来源不可用时，返回 UNKNOWN 而非空值或猜测。错误的不确定比诚实的未知危险得多。
02 冲突即搁置CONFLICT 多个来源对同一事实不一致时返回 CONFLICT，附上双方证据，由你裁决。
03 配置先验证validate / doctor 规则在生效前必须通过 validate；doctor 逐项体检运行环境，问题在值班前暴露。
04 指纹去重SQLite memory 信号状态、证据指纹、新闻指纹持久化在本地 SQLite，重启后不重报、不漏报。
05 新鲜度与时区NSE / HKEX 美股按纽约时区、港股按香港时区感知交易日；交易所日历自动过滤休市日，过期数据不进入结论。

Quick Start

三步开始值班

默认离线、只读、不联网不通知——能力逐层显式启用，安全默认值不需要你配置。

STEP 1

克隆并同步

Python 3.11 / 3.12，uv 冻结安装，可复现环境。

$ git clone https://github.com/sunhetong918/alpha-guard.git
$ uv sync --frozen
可选 extras：notifications / desktop / ai / cn-data
STEP 2

验证配置

规则先过 validate，环境先过 doctor，再谈运行。

$ alpha-guard validate
$ alpha-guard doctor
任何一项不过，都不会进入值班
STEP 3

空跑值守

dry-run 先看结论与证据，确认后再启用通知。

$ alpha-guard dry-run
输出：SILENCE (trusted) 或附证据的信号
